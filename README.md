# Rmho — Rokoi Monster Hunter Outlanders (guide)

Unofficial, fan-made guide app for **Monster Hunter Outlanders**, built for the
Rokoi hunter community. Not affiliated with Capcom, TiMi Studio Group or Garena.

## Features (roadmap)
- Adventurers database (class, weapon, element, skills, ultimate) with photos
- Monsters: elemental weaknesses, breakable parts, loot
- Items & materials with farming sources
- Team compositions
- Rotation guides + **Coach**: practice mode, fight-recording analysis,
  and a live on-button rotation guide during hunts
- Remote data updates (JSON + images) without a new APK

## Tech
Kotlin + Jetpack Compose + Material 3. Builds run on GitHub Actions
(see `.github/workflows/build.yml`); the debug APK is published as a
workflow artifact.
